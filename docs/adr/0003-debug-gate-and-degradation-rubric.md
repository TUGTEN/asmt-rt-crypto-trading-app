# Debug visibility: ?debug/backtick gate with exchange rubric always on

Tier plus chart rate, RTT/2 latency, jitter EMA, and live-vs-stale ribbons stay permanently visible in the green/yellow/red/gray exchange rubric; the DEBUG force panel and backend switcher render only with `?debug=1` or the backtick key (ignored in inputs), animating via CSS grid-rows, so visitors never see dev controls while a user can still force tiers for the recording.
